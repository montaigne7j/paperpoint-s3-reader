# V1.8.3 reader background and guide lines

V1.8.3 adds an optional reader-page decoration layer.  The renderer checks `/bg` for visible `.png` files and uses the first sorted PNG when `readerBackgroundPng` is enabled.  The PNG is drawn before text and before the status bar, so it becomes part of the page-frame cache.

Guide lines are also drawn from the actual page row/column positions.  Horizontal layout draws faint baselines beneath rows.  Vertical layout draws faint guides to the left of text columns.  Available styles are solid, dashed, and dotted.  The faint pattern is relative to each segment rather than to absolute framebuffer parity, avoiding the old issue where 1px light-gray dither lines could vanish on odd x/y coordinates.

Reader background PNG rendering supports an optional fade-to-white percentage.  The device setting is `readerBackgroundFadePercent`, exposed as **Reader background fade** from 0% to 90% in 10% steps.  The fade is applied before 4-level e-ink dithering so decorative backgrounds remain readable behind text.

This update intentionally leaves the V1.8.x FreeType PSRAM allocator, background TTF miss abort, idle glyph prewarm, input responsiveness, and page-turn waveform logic unchanged.
