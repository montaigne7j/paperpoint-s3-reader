# V1.8.2 font and navigation refinements

V1.8.2 is a compatibility and usability update for Paper S3.  It keeps the V1.8.x memory, waveform and input-responsiveness strategies unchanged while improving external bitmap font handling and several navigation details.

## Font scanning

- Scan both `/fonts` and `/font`.
- If the same filename appears in both folders, `/font` wins.
- This makes `/font` a user override folder while preserving compatibility with the earlier `/fonts` convention.

## External bitmap font filenames

The legacy `.bin` parser is now more tolerant.  It accepts CJK names, spaces and symbols, and dimension tokens such as:

- `23x30`
- `23X30`
- `23×33`

The preferred form remains `Name_size_WxH.bin`, but `Name_WxH.bin` and names with spaces/symbols are also accepted.

## External BIN scaling

Legacy external `.bin` reader glyphs now scale with Reader Font Size.  Older builds changed the layout cell size but drew the original bitmap unchanged, which made external `.bin` fonts look fixed-size.

## Spacing

Reader character spacing can now be negative for experimental external bitmap fonts.  This is intentionally permissive: overlapping glyphs are allowed because the setting only affects reader layout and does not modify the system UI font.

## Navigation

- File Browser footer Back leaves the File Browser in one tap.
- EPUB Chapter Selection footer buttons now mean Exit / Select / Parent / Next-page.
- The Parent button is hidden when the selected TOC item is already at the top level.

## Home icons

The Lyra home menu icons for Browse Files, Recent Books, File Transfer and Settings are rotated 90° left.  The Power icon is left unchanged.
