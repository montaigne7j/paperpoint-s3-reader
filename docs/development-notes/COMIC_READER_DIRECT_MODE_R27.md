# R27 Comic Reader Direct Mode and Pocket Lock

## Goals

This release is based on `paperpoint-s3-reader-v1.8.4-r26g-cbz-wdt-reset-fix.zip`.

## Comic reader mode

The Home screen now separates:

- Novel Reader: normal file browser rules for EPUB/XTC/TXT/MD/BMP.
- Comic Reader: comic file browser rules for ZIP/CBZ archives.

The CBZ reader is optimized for CBZ files generated by the Paper S3 comic converter.
These pages are expected to be prepared for the Paper S3 panel, typically 540 px wide and not taller than the image area.

The reader therefore no longer scales a converted comic page to fit the long edge.
It draws the image at native size, centered only when narrower than the screen, top-aligned, and leaves remaining space white above the fixed status bar.

## Pocket lock

Reader input is ignored when the device is physically inverted relative to the IMU baseline.
This is intended for pocket carry: accidental touches do not page-turn or open menus.
Auto-sleep timing still counts while locked.

The lock uses M5Unified IMU if available. If the IMU cannot be initialized, the feature is disabled and normal reader behavior is preserved.
