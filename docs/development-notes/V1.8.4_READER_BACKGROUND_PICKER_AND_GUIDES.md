# V1.8.4 reader background picker and guide-line alignment

V1.8.4 replaces the simple first-PNG background mode with a reader background selector. The selector scans `/bg` and one nested level so users can organize decorative PNGs in subfolders. The selected path is persisted in `readerBackgroundPngPath`.

Guide lines are rendered from actual cached `PageLine` positions after the text pass, rather than from a synthetic grid. Horizontal pages draw baselines below text rows; vertical pages draw column guides to the left of text columns. This fixes guide-line drift and makes lines visible with large page margins such as 40 px.

Sleep image scanning now includes `/.sleep`, `/cover`, and `/sleep`, then legacy root files.
