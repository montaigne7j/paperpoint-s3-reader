# R28 CBZ fast page cache

R28 focuses on faster comic page turns for CBZ files generated by the Paper S3 comic converter.

## Changes

- Fixed the CBZ status bar separator line using `screenW - 1` instead of `screenW`, because draw line end coordinates are inclusive.
- Kept converted images at native size and added a next-page decoded framebuffer cache.
- After the current page is displayed, the activity preloads `currentPage + 1`:
  1. Extract the next ZIP entry.
  2. Decode JPEG/PNG/BMP to the normal renderer framebuffer without displaying it.
  3. Copy the framebuffer to PSRAM.
  4. Restore the visible current page framebuffer.
- On the next page turn, if the target page matches the cache, the cached framebuffer is copied back and displayed directly.
- Comic reading maps left-side content tap to next page and right-side content tap to previous page.

## Notes

For best performance, use CBZ files produced by the converter v4b or newer, which outputs ZIP_STORED by default. JPEG files are already compressed, so ZIP deflate usually saves little space but adds CPU cost on the device.
